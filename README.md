# Rock Paper Scissors Game in Python 🎮

This project is a simple command-line Rock Paper Scissors game built using Python.  
It allows a user to play against the computer, which randomly selects its move.

This project is ideal for beginners who want to practice:
- Python basics
- Loops
- Conditional statements
- User input handling
- Random number generation

---

## 🧠 Game Rules

- Rock vs Paper → Paper wins  
- Rock vs Scissors → Rock wins  
- Paper vs Scissors → Scissors wins  

---

## 🛠️ Technologies Used

- Python 3
- Built-in `random` module

## 🎯 How the Game Works (Step-by-Step)
The game displays the winning rules.
The user chooses:
1.For Rock
2.For Paper
3.For Scissors
The computer randomly selects one option using randint().
The winner is decided based on predefined rules.
The user is asked if they want to play again.
The game continues until the user chooses to exit.
